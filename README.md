# Cupid's Closet

Cupid's Closet NO es una tienda única. Es una herramienta inspirada en Shopify para que emprendimientos de ropa puedan crear y administrar su propia tienda online.

## Qué incluye esta versión

- Landing de Cupid's Closet.
- Panel de administración.
- Gestión de productos.
- Panel de pedidos de ejemplo.
- Personalización del nombre, eslogan, colores y tipografía de la tienda.
- Vista previa del diseño.
- Tienda pública separada.
- Filtros de productos.
- Carrito.
- Función “Encontrá tu outfit”.
- Guardado con localStorage para que funcione sin base de datos.

## Archivos

- `index.html`: página de presentación de Cupid's Closet.
- `dashboard.html`: panel tipo Shopify.
- `tienda.html`: ejemplo de la tienda creada por el usuario.
- `estilos.css`: diseño general.
- `app.js`: funciones compartidas y datos.
- `dashboard.js`: gestión del panel.
- `tienda.js`: catálogo, carrito y outfit finder.

## Abrir en Visual Studio Code

1. Descomprimí la carpeta.
2. Abrí Visual Studio Code.
3. Elegí `Archivo > Abrir carpeta`.
4. Seleccioná `CupidsCloset_ShopifyTool`.
5. Abrí `index.html`.
6. Si tenés Live Server, hacé clic derecho y elegí `Open with Live Server`.

## Importante

Esta es una versión frontend del prototipo. El siguiente paso técnico sería conectar Node.js + Express + SQL para crear usuarios, tiendas reales, pedidos persistentes y cuentas separadas.
